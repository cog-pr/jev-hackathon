# 今、何やる？

> Todoを管理するのではなく、**「今、何から手をつけるべきか」**を決めてくれる学生向けタスクアプリ。

大学生活では、課題・授業・就活・資格勉強など、種類の違うタスクが同時に発生します。一般的なTodoアプリはタスクを整理できますが、最後の「どれから始めるか」は自分で決めなければなりません。

「今、何やる？」は、タスク情報と現在の状況をJevに渡し、**今取り組むべき順番**を提示します。締切だけでなく、使える時間・集中力・場所・PCの有無も考慮するため、同じタスク一覧でも状況に応じて順位が変わります。

## 主な機能

- 自然文からタスク名・締切・所要時間を抽出
- タスクの手動登録・完了・削除
- 自宅／移動中の状況プリセット
- 使える時間・集中力・場所・PCの有無を反映
- 繰り返し予定から、次の予定までの空き時間を自動計算
- Jevによる4段階の優先度判定とランキング
- 優先する理由と、着手を妨げる要因の表示
- 状況やタスクが変わったときの自動再判定
- タスク・予定・状況をブラウザの`localStorage`に保存

## デモの見どころ

1. 「デモ用タスクを読み込む」を押します。
2. 「自宅モード」を選び、まとまった時間とPCがある状況の順位を確認します。
3. 「移動中モード」に切り替えます。
4. 同じタスクでも、使える時間や作業環境によって順位が変わることを確認します。

自然文入力も試せます。

```text
明後日23:59までに機械学習のレポートを提出。成績の30%を占める。2時間くらいかかりそう。
```

Jevが締切と所要時間の候補を選び、確認・修正してからタスクとして追加できます。

## セットアップ

### 必要なもの

- Node.js 20.6以降
- npm
- TypeSafe / JevのAPIキー

### インストール

```bash
npm install
```

プロジェクト直下に`.env`を作成し、APIキーを設定します。

```dotenv
TYPESAFE_API_KEY=your_api_key
```

ポートを変更する場合は、任意で`PORT`も指定できます。

```dotenv
PORT=3000
```

> `.env`はGitの管理対象外です。APIキーをクライアント側のコードへ記述しないでください。

### 起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

Jev APIとの接続だけを確認する場合は、次のコマンドを実行します。

```bash
npm run check-api
```

## 仕組み

```text
タスク情報 ─────────────┐
                        ├─ Expressサーバー ─ Jev ─ 優先順位と判断理由
現在の状況・空き時間 ───┘                         │
                                                   ↓
                                          「今やる順」を表示
```

ランキングは、Jevの`Score`が返す「今この状況でどれくらい優先して取り組むべきか」の値で決まります。JavaScript側で複数のシグナルに独自の重みを付ける処理は行っていません。

Jevの役割は次のとおりです。

- `Score`: 各タスクの優先度を4段階で判定
- `Choice`: 優先する主な理由、妨げの種類、自然文中の締切・所要時間候補を選択
- `Noul`: 今の状況で着手を妨げる要因があるかを判定

自然文入力では、通常のコードが日付・時間表現の候補を抽出し、Jevは候補の中から適切なものだけを選びます。文章にない締切や所要時間を生成しない設計です。

## TaskとScheduleの扱い

- **Task**: ユーザーが取り組む候補。Jevのランキング対象です。
- **Schedule / Constraint**: 授業やバイトなど、作業できない時間を表す制約です。ランキング対象にはせず、空き時間や次の予定を求めるために使います。

現在の予定入力UIは、外部カレンダー連携前のデモ用です。通常のカレンダーアプリへ拡張することは、このプロダクトの目的ではありません。

## 技術構成

- Node.js
- Express
- Vanilla HTML / CSS / JavaScript
- TypeSafe SDK / Jev
- localStorage

APIキーはExpressサーバー内だけで使用し、ブラウザには渡しません。

## 現在の制約と今後

現時点では、タスク・予定・状況は手動入力またはデモデータで登録し、ブラウザ内に保存します。Google Calendar、LMS、メールなどの外部サービスとはまだ連携していません。

将来的には、タスクと現在状況の入力を外部サービスから自動化し、アプリを開くだけで「今はこれをやる」と提示される状態を目指します。

詳しいプロダクト仕様と設計思想は[仕様書.md](./仕様書.md)を参照してください。
